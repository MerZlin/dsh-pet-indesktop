# Phase 7：正式发布与跨平台验收

> **状态：发布前验收（2026-09-25）；不是当前开发前置条件**

Phase 7 保留 Windows、macOS、Linux 的正式发布方向，但开发阶段不要求每次提交都完成三平台实机。发布前必须集中完成以下验收：

- 三平台基础启动、目录权限、配置迁移和退出；
- Starter DLC 发现、安装、角色切换、升级和回滚；
- Worker 启动、心跳、崩溃恢复、父子进程清理和降级；
- Core 与 DLC 分离更新；
- 插件诊断导出和故障恢复；
- 包体、启动时间、RSS、CPU、事件延迟、下载体积和日志增长基线；
- 正式内容/Worker 的签名、公钥轮换、撤销和兼容矩阵；
- API 弃用、迁移和发布说明。

## 发布门

未满足上述证据时，Phase 7 不得被描述为“完成”，也不能用 CI offscreen 结果冒充可见桌面验收。Phase 5/6 未启用时，正式发布仍可以只包含 Core、Starter DLC 和官方能力。

## 失败影响

Phase 7 失败不应影响已验证的 Core、Phase 1 资源 DLC、Phase 2 官方插件或 Phase 3A 的可回滚实现。缺失的分发/生态能力应保持禁用，而不是成为启动硬依赖。
