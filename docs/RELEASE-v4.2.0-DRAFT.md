# v4.2.0

> **v4.2.0 是自 v4.1.0 以来的开发增量版**（main @ `243e4cb`，2026-09-09 基线），覆盖 PR #64/#65/#68/#70/#71/#72/#73/#76/#79/#80/#82/#85 及大量直推修复。本版主线围绕四件事：**内存长稳与单进程多开**、**设置与菜单可配置重构**、**边缘交互玩法与子肥鱼生命周期**、**Agent/DSH 生态与桌面兼容修复**。
>
> 安装/绿色包均为 onedir 形态：运行期不产生临时缓存，启动快、卸载干净。仍只发布 **WebM** 变体（GIF 变体自 v4.0.0 起停供）。

---

## ⚠️ 注意与升级提示

- **新开关大多默认关（灰度）**：单进程多开、边缘探头、闲置降帧（省电模式）、黄金回旋直连等为显式开关，需要请在设置中开启；单进程多开与省电模式改动后**重启**生效。
- **「清除子肥鱼」改为「退出子肥鱼」**：现在**只退出、不删除**该子肥鱼的设置/会话/待办数据，下次生成原样恢复；操作不再弹确认框，结果写日志。
- **老版本明文 API Key 会自动迁移**：≤v4.0.0 写在磁盘明文里的 Key 首次启动会自动迁入系统 keyring（含视觉 Key），无需重配；如遇聊天 401 请先确认系统 keyring 状态。
- 旧实验配置（`decode_broker_enabled` 等被替换键、`click_sound_path`/`throw_max_speed` 派生键）会自动清理/迁移，残留值无害。
- 延续的已知限制（详见 README）：安装包/安装器未签名（SmartScreen/Gatekeeper 需手动放行）；macOS 仅发布 Apple Silicon（arm64）；Linux 仅 x86_64 + 需少量系统库、建议 X11；GIF 变体不再发布。

## 🔔 关于“系统通知”（为什么还没有系统级原生弹窗）

本版**仍未接入系统原生通知弹窗**（Windows 操作中心 toast / macOS 通知中心 / Linux 桌面通知）。AI 对话的“对话完成 / 生成失败 / 需要授权”目前只在聊天界面不在前台时用**应用自绘的右下角提示气泡**提醒（点击可跳回会话或打开 AI 设置）。原因：

- **Windows**：`QSystemTrayIcon.showMessage` 的原生气泡在托盘图标被系统收进“隐藏的图标”区域时可能不弹出（v4.1.0 评估后弃用该通道）；要真正进入 Windows 通知中心还需设置 AppUserModelID 并调用原生通知 API，在 PyInstaller 冻结、多实例、绿色版与安装版并存下，打包身份与升级路径的验证成本高。
- **macOS**：系统通知需要用户授权，且对签名打包的 `.app` 强依赖；当前未签名/绿色分发下不可靠。
- **Linux**：桌面通知依赖各发行版的 DBus/notify 服务，行为不一，难以做三平台一致承诺。

三平台一致且可靠的原生通知列入后续待办；在此之前不把“系统通知”作为正式可用能力宣告，如有相关设置/文案以本说明为准。

## ✨ 新功能

### 🖥️ 内存专项与单进程多开（PR #76）
- **单进程多开（省内存）**：设置 → 常规 → 多开 新增开关（`experimental_single_process_spawn`，默认关，重启生效）。开启后「生小肥鱼」在同一进程内孵化多只桌宠（独立配置/会话/素材库）。实测单进程 3 窗 ≈ **181–197MB**、3.5h 内存无单调上涨；多进程模式 ≈270MB/3 只。
- **同角色共享解码链**：多窗同角色只保留 **1 条 ffmpeg 解码链**（进程内帧扇出 `DecodeFanoutHub` 取代早期 shm broker），订阅窗零解码开销。
- **多窗托盘聚合**：单托盘 + 每窗子菜单（显示/隐藏、切换角色、退出这只）；灵动岛单击聚合全部窗；主窗退出自动提升下一窗为主。
- **slot 落种**：新子肥鱼初始配置跟随主设置（剔除位置键），已有存档一律保留；支持继承主大小/独立尺寸/灵动岛（`spawn_inherit_size`/`spawn_scale`/`spawn_inherit_dynamic_island`）。

### 🎛️ 设置系统重构与可配置菜单（PR #64，ushio2026-alt）
- 设置页重组为**七个能力域**（常规/桌宠/互动/菜单/桌面组件/AI 与对话/自动化与联动），菜单域页内 Tab：菜单编排 / 快捷启动 / 外观。
- **右键菜单可编排**：显隐、移动到子菜单/根、新建子菜单、**分割线**、**别名**（运行时只显别名）、**图标覆盖**（内置矢量或本地图片 ≤5MB，contain/cover），左侧编辑、右侧**实时预览**；损坏配置自动回退安全菜单，旧自定义树自动补齐新默认项。
- 菜单颜色主题成为设置窗口的显式主题来源（即时整页生效）；开关从属项统一「开显关隐」。
- 图片目录**预览抽屉**（自言自语/彩蛋，3 列瀑布流缩略图）；快捷启动应用列表编辑；macOS 原生 Dock 右键菜单（显示桌宠/桌宠设置/AI 对话/退出）。

### 🎏 边缘交互与彩蛋玩法（PR #79/#85）
- **黄金回旋**：右键菜单新入口；「点击触发黄金回旋」`golden_spin_on_click` + 「直连回旋跳过动画」`golden_spin_direct`——连点逐圈累计加速（700ms→×0.82→200ms 下限）。
- **边缘探头** `edge_probe_enabled`：拖到屏幕边缘 ±45° 探头贴边（常驻露出 0.55、点击拉直 0.82、数秒自动退回），探头激活时点击静音。
- **撞飞彩蛋**：探头激活状态被撞飞时整帧旋转、头部跟随速度方向，低速贴边/撞宠回正，落地停稳 5s 后自动重新贴边。
- 托盘与多窗子菜单「回到右下角」（先取消探头姿态，不再倾斜着拖回去）。

### 🐟 子肥鱼生命周期（PR #85）
- 一键「退出子肥鱼」**只退出不删数据**（见顶部提示）；覆盖单进程/多进程两种模式。
- 生命周期健壮性：杀进程前核验 pid 身份（防复用误杀）、真死活判定、全程无控制台弹窗、未拖动过的新生鱼也能被枚举、slot-0（主鱼）永不误杀。

### 📌 待办提醒（PR #72，shinelon）
- 右键菜单「待办」面板增删改；到期/提前提醒（提前量可设 0–60min），桌宠可见时气泡提醒、否则桌面通知；10 分钟宽限、一次性待办自动归档，错过宽限的提醒静默盖戳不补爆；数据按实例落盘。

### 🤖 Agent 联动与 DSH 生态（PR #73/#76/#80/#82）
- **DSH 富事件状态**：thinking/working（带工具名）/attention/error 多态呈现，子代理不抢状态。
- **opencode 修正**：`tool-calls` 阶段不再误报完成——长跑子代理/慢工具不再触发假完成音与气泡。
- **启动复用已有实例**：本机已在跑 dsh web（含官方 3080）时直接复用，不再拉起第二个；需新起时冒泡「正在后台启动」。
- **「随桌宠启动 dsh 服务」**（`harness_autostart`，设置→常规→应用启动，仅主鱼可设）：自启动时后台只起服务、不弹浏览器与窗口。
- **启动链路静默化**：探测子进程不再闪现终端；`--no-open` 探测三级落盘缓存 + 超时放宽——修复开机高负载下 dsh 自弹浏览器（issue #10）。

### 👀 看看屏幕 / 主动识屏 / 灵动岛（PR #73/#80）
- **识屏自我识别**：模型知道自己就是桌面里的宠物形象，以第一人称回应，不再把角色说成「陌生程序」。
- 灵动岛余额**峰谷按系统时间档位**显示「当前档位→下一档切换时间」，准点自动重排。
- 可选服务开关式懒加载（碰撞/待办/识屏/联动关闭即不装配）。

### ⚡ 流畅度（PR #70）
- 高刷屏（>90Hz）位置更新节拍跟随刷新率（165Hz→6ms、120Hz→8ms）；定时器改精确定时器；拖拽 ~120Hz 合帧；碰撞预测限频、状态上报先限流。

### 🔐 安全 / 兼容 / 跨平台（PR #68/#71/#79）
- API Key 明文自动迁移 keyring（#68）。
- Linux 随包 ABI 匹配的 Fcitx5 输入法插件，中文输入法（Fcitx/Rime）可用（#71）。
- 直播捕获（OBS/直播姬）兼容：快速对话气泡并入主窗子内容、可点击、保持向上生成（自动申请透明头顶空间）；不再冒空白小气泡（#79）。
- macOS：Dock 隐藏彻底生效 + 恢复提示；Finder 启动的 Node/Homebrew 解析（issue #67）。

### ✨ 其它（含小项）
- 自言自语**气泡配图大小可调**（`self_talk_image_scale` 50–300%）。
- 会话保存全面原子化/异步化：多前端并发写入不再互相覆盖，生成中另开窗口写入不丢。
- 桌宠可**拖文件模拟吃掉**并记录统计（不真实删除）。
- 动画素材 97→106（同步上游 9 个）；icon 确定性重建。
- 快捷启动：无配置项时子菜单保留并显示禁用占位；彩蛋入口深色主题文字可读。
- 点击音效预热时机收敛、播放前显式 stop（不再无声）。
- 配置作用域说明文档化：每窗独立项 vs 进程级共享项。

## 🐛 主要 Bug 修复

- **打字时桌宠频闪（Windows，根治）**：全屏判定排除工具窗口/截图覆盖层（PixPin 类），穿透切换改原生 `WS_EX_TRANSPARENT`（不再重建原生窗口）。
- **WebM 播放进程与线程泄漏**：僵尸 reader 根因修复、ffmpeg 子进程显式终止、GUI 永不 join 退役 reader（连点不再卡顿）、切换失败不再静默停滞。
- **主进程内存慢涨（90→260MB）**：非显示 clip 清空显示槽（15min 恒定 3.5MB）。
- **子肥鱼**：杀不掉/误杀主鱼/pid 复用误杀/覆盖用户存档/删光数据/弹控制台等整族修复（见上）。
- **dsh/DSH**：开机自启弹浏览器与空终端、双开拉起第二个实例、`tool-calls` 假完成、macOS 找不到 node。
- **POSIX 多开选举死循环**（issue #42）：残留 socket 探测清理。
- **会话与文件**：生成期间整会话覆盖他端写入、删除会话后幻影写入、瞬时文件锁 WinError 5。
- **音效**：首次点击/试听无声、后续无声。
- **显示/缩放**：跨 DPI 屏与系统缩放变化画面未重建、素材原地替换后旧帧残留、squash 命中 mask 错位。
- **macOS**：Dock 隐藏不彻底（issue #74）、快速对话残留空白窗。
- **Linux**：文本框无法用 Fcitx/Rime 输入中文（#71）。
- **老配置升级**：磁盘明文 Key 在升级后聊天/视觉静默 401（#68）。
- 三方盲审批次（17+ 项健壮性）：畸形碰撞消息、更新检查重入、>7 天日志清理、SSE 心跳行、设置 Esc 关闭落盘、图标解码超时逃生等。

## ⚡ 性能与内存（实测）

- 三开热机 361–402MB/只 → 单进程多窗 3 窗 **181–197MB**、3.5h 无单调上涨；双窗 340MB vs 双进程 460MB。
- 同角色多窗 ffmpeg 子进程数 = 1；ffmpeg `-threads 1` 每进程 −13MB；圈边界定期回收周期爬升。
- 闲置降帧（省电模式）解码 CPU **−54.6%**（台架）；闲置期 CPU 明显回落、交互即回满帧率。
- 预测式首帧预热 350ms + 交互链首帧常驻：高强度交互定格 8→1~2 次/局。
- 高刷屏拖拽/弹跳平滑；碰撞风暴 CPU 61%→43%。
- 关闭全部音效时不再加载 QtMultimedia（约 38MB）；PIL 延后导入。
