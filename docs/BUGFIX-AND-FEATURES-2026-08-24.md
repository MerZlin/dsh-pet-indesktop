# 桌宠焦点、图标与“生小肥鱼”开发记录

日期：2026-08-24

## 目标

1. 自言自语气泡显示时不抢走其他应用的输入焦点。
2. 放大可执行程序图标中的角色，并保证构建使用最新图标。
3. 在桌宠右键菜单新增“生小肥鱼”，启动一个独立的新桌宠进程。
4. 为桌宠右键菜单补充统一、适合当前平台的图标。

## 开发计划

1. 检查窗口创建、气泡显示、图标生成、打包入口和右键菜单代码。

4. 运行功能测试与现有回归测试，检查生成图标的实际可见范围。
5. 记录实现决策、验证结果和人工验收步骤。

## 实现过程

### Bug 1：气泡抢输入焦点

- 保留 macOS 的 accessory 应用激活策略，阻止定时出现的工具窗口激活整个应用。
- 将 `WindowDoesNotAcceptFocus` 从仅 macOS 扩展到所有平台。它是窗口级硬约束；`WA_ShowWithoutActivating` 仍作为 Qt 层的辅助提示。
- 气泡继续使用 Qt 的 `show()`，避免绕过 Qt 后不触发绘制。

涉及文件：`pet/speech_bubble.py`、`pet/app.py`。

### Bug 2：可执行程序图标中的角色太小

- 将图标裁剪与合成提取为可测试的 `prepare_icon_image()`。
- 使用 alpha 大于 8 的区域计算真实角色边界，忽略透明视频边缘的低 alpha 噪点。
- 保持比例，将角色最长边放大到图标画布约 97.7%。
- Windows 构建脚本每次在 PyInstaller 之前执行 `scripts/make_icon.py`，避免继续打包旧的 `icon.ico`。
- 运行时菜单/托盘图标也先裁掉透明画布，避免“生小肥鱼”菜单图标再次显得很小。

实际预览的有效 alpha 边界为 `(28, 3, 228, 253)`，最长边为 250px。

涉及文件：`scripts/make_icon.py`、`scripts/build_onedir.ps1`、`pet/window.py`。

### New function 1：“生小肥鱼”

- 新增 `pet/instance_launcher.py`。
- 打包环境重新启动 `sys.executable`；源码环境使用 `python -m pet`。
- Windows 使用 detached process flags，macOS/Linux 使用新的 session；父桌宠退出不会带走新桌宠。
- 新实例通过环境变量获得递增错位序号，启动后向屏幕内侧错开，避免与母桌宠完全重叠而看不出已经启动。
- 启动失败时记录日志并显示错误信息。

涉及文件：`pet/instance_launcher.py`、`pet/app.py`、`pet/window.py`。

### New function 2：右键菜单图标

- 将菜单构建抽成 `_populate_context_menu()`，使动作、图标和回调可独立测试。
- 采用 Qt 当前平台的标准图标，让 Windows/macOS 上的线条、尺寸和主题自动匹配系统样式。
- AI、设置、动画、播放速率、拖动物理、角色、复位、置顶、停止移动、自启、大小、Harness 和退出等直接菜单项/子菜单均已配置语义图标。
- “生小肥鱼”使用裁剪后的当前角色头像图标。

涉及文件：`pet/window.py`。

## 2026-08-26：设置窗口密度与自言自语气泡方案

### 设计分析

- 参考 Otty 设置窗口，将桌宠设置初始尺寸从 `860×620` 收紧为 `800×560`，最小尺寸调整为 `720×500`；侧栏从 200px 收窄到 188px。
- 延续商业应用中“低对比侧栏 + 清晰内容层 + 轻边框卡片”的层级：侧栏、内容背景、选中/悬停色不再使用同一灰阶，搜索框默认弱化边框，聚焦时再显示蓝色反馈。
- 页面边距与标题尺寸略微收紧，保留设置项左侧标题/说明、右侧操作控件的稳定扫描路径；功能分组不因视觉调整而改变。

### 气泡方案

- 保留兼容默认项“经典暖黄 · 正上方”。
- 新增“纸感卡片 · 左上方”：白色纸张表面、细灰边框和偏左尾部。
- 新增“深色玻璃 · 右上方”：深色高对比浮层、大圆角和偏右尾部。
- 新增“柔蓝对话 · 正上方”：浅蓝对话表面和柔和蓝色描边。
- 四套方案不是简单换色：圆角、明暗对比、边框、阴影、尾部锚点及首选相对方位均独立定义。
- 统一安全布局器按角色的实际可见矩形定位；首选位置空间不足时依次尝试其他上方位置、左右侧和下方，并在屏幕范围内钳制，优先选择与角色零相交的位置。
- 气泡仍使用不激活窗口属性，并在桌宠移动时重新定位，因此不会抢输入焦点且会相对角色持续跟随。

### 验证

- 新增配置默认值、非法值回退、持久化、四套方案差异和不遮挡角色的测试。
- 更新设置面板测试，覆盖初始/最小尺寸、侧栏宽度、Otty 风格层级、下拉选项和保存结果。
- 离屏渲染人工检查了设置常规页、外观页和四套气泡，未发现文字裁切或尾部错位。
- 完整回归：`111 passed`（两项本机回环端口测试在获准环境中执行）。

### 气泡轮廓二次视觉修复

- 根因一：旧实现先绘制圆角矩形，再单独绘制三角尾巴，矩形底边仍从尾巴根部穿过，造成尾巴像后贴上去的错误层级。
- 根因二：顶层透明窗口使用 `QGraphicsDropShadowEffect` 时，阴影扩散区域会被窗口矩形裁切；macOS 上最终呈现为气泡下方突兀的整块灰色托盘。
- 将圆角主体路径与尾巴路径执行几何合并，形成单一矢量轮廓，再统一填充和描边，根部不再存在内部边线。
- 移除不稳定的窗口图形特效，改为沿合并后轮廓绘制两层低透明度、最大 2px 偏移的环境阴影；阴影同时覆盖主体和尾巴，且不会越界形成灰色硬块。
- 尾巴宽度收紧并向主体内部嵌入 2px，四套气泡在上、左、右回退位置都会重新生成对应方向的连续轮廓。
- 新增回归测试，验证无 `QGraphicsDropShadowEffect`、尾巴内部属于统一表面路径且阴影偏移不超过 2px。

### 新增“吐气水泡”方案

- 依据参考图新增“吐气水泡 · 左上方”，使用单独的有机水泡绘制器，不复用圆角矩形或三角尾巴。
- 主体由多段三次贝塞尔曲线构成不规则椭圆，使用深青色粗圆角描边和近白色填充。
- 浅蓝色底部液面通过曲线路径绘制，并裁切在主体轮廓内部。
- 右上角绘制一长一短两段深青色反光笔触；右下角绘制一大一小两个独立呼吸泡，结构和参考图一致。
- 该方案禁用阴影，默认置于角色左上方，使右下呼吸泡自然指向角色；统一安全布局仍确保完整气泡矩形不遮挡角色并跟随移动。
- 配置白名单、外观设置下拉菜单、持久化和单元测试同步增加第五种方案。

### 吐气水泡参考图比例校准

- 对参考图与首版渲染进行归一化测量：参考主体宽高比约 `1.22`，首版约 `1.65`。将水泡画布高度增加并重算贝塞尔控制点，最终主体比例约 `1.20`。
- 浅蓝水面起点由主体高度 58% 上移到 48%，拆成两段不对称三次曲线，增大水体面积并避免规则抛物线观感。
- 长反光横向跨度限制为主体宽度 15%，短反光限制为 4.5%；同时压缩纵向落差并整体上移。
- 大、小呼吸泡改用各自独立的三段三次贝塞尔闭合轮廓，不再调用标准椭圆 API。
- 三个水泡按实际路径边缘距离布局；主体到大泡、大泡到小泡的最近距离均约 2–7px，差值不超过 2px。
- 新增几何回归断言，覆盖主体宽高比、水面起始比例、反光长度、不规则轮廓复杂度和三泡等距关系。

### 吐气水泡相对桌宠尺寸优化

- 根因是吐气水泡沿用参考画布的固定最小尺寸 `240×195`，没有读取桌宠透明画布中角色的实际可见轮廓；在小尺寸桌宠旁边，气泡主体因此明显大于角色。
- 新增基于角色 alpha-mask 可见矩形的自适应尺寸计算：水泡宽度取角色可见宽度的 82%，并限制在 `168–216px`，高度继续保持参考画布 `240:195` 的比例。
- 主体贝塞尔轮廓、液面、两枚离散呼吸泡、反光线、文字内边距和描边同步按画布比例缩放，避免只缩窗口造成轮廓变形或文字越界。
- 尺寸只在显示新文本时根据当前角色轮廓确定；桌宠移动期间只更新锚点位置，避免不同动画 alpha-mask 轻微变化导致气泡持续抖动。
- 新增小/大桌宠尺寸边界、气泡不遮挡角色和缩放后主体宽高比的回归测试；离屏渲染确认两行文本、液面与呼吸泡均完整显示。

### 吐气水泡与桌宠视觉间距修复

- 自适应缩小后水泡看起来离角色更远，根因不是锚点丢失，而是通用布局器按透明窗口底边预留 12px；水泡参考画布的小呼吸泡下方另有约 17–24px 透明留白，两段距离发生了叠加。
- 吐气水泡在首选上方位置时改为按完整绘制路径的最下边缘定位，使最小呼吸泡到角色可见轮廓顶部保持约 7px；透明窗口允许轻微覆盖角色矩形，但实际绘制路径仍不得与角色相交。
- 屏幕边缘钳制和其他气泡样式继续使用原通用安全布局，不受该视觉补偿影响。
- 回归测试由检查透明窗口矩形改为检查真实绘制路径，覆盖 `5–9px` 视觉间距以及水泡路径与角色零相交。

## 2026-08-27：气泡内容重排、缩放同步与图片自言自语

### 问题根因

- 吐气水泡尺寸此前只在 `show_text()` 中按当前帧 alpha-mask 宽度计算；桌宠切换大小时 `reposition()` 只更新位置，已显示气泡不会重算宽高。
- `change_scale()` 先移动窗口、后重建帧与 mask，移动事件可能让气泡读取缩放前轮廓；同时 `168–216px` 的硬上下限会让相邻桌宠档位落入相同平台值。
- “看看屏幕”的完整 Markdown 回复直接进入为短句设计的气泡，固定文本矩形没有使用实际文本高度，造成 `##` 裸露、反光区域拥挤和正文裁切。
- 自动自言自语从气泡出现时开始计算下一次间隔；当显示时长大于最短间隔时，新内容会在旧内容消失前覆盖。

### 实现方案

- 气泡缩放改由桌宠稳定 `scale` 决定，四个有效档位使用严格递增尺寸；alpha-mask 只负责位置和防遮挡，不再让动画当前帧改变气泡大小。
- 桌宠缩放流程在新帧和新 mask 建好后调用气泡 `reflow()`，一次完成内容尺寸、轮廓和锚点重排。
- Markdown 标题、列表和强调标记转换为纯文本，气泡最多显示三行并对剩余内容使用省略号；完整 AI 回复仍同步到本地对话记录。
- 吐气水泡文本安全区下移，避开右上反光笔触；液面和水泡轮廓保持原参考比例。
- 新增 `self_talk_image_dir`，桌宠行为页提供绝对路径输入框和原生目录选择器；PNG、JPEG、WebP、BMP、GIF、TIFF 等常见格式与文本共同进入随机池。
- 新增 `self_talk_duration_seconds`，默认沿用原气泡时长 `3.2` 秒，可配置 `1–300` 秒。
- 最短/最长间隔重新定义为“上一条气泡消失后到下一条出现前的空闲时间”；自动或点击显示自言自语后，定时器按 `显示时长 + 随机空闲间隔` 启动，彻底避免配置冲突和内容互相覆盖。

### 验证覆盖

- 四档气泡尺寸严格递增，显示期间切换桌宠大小会在 mask 重建后立即重排。
- 长 Markdown 回复去标记、最多三行且带省略号。
- 图片目录配置规范化、格式过滤、随机图片显示和图片气泡缩放。
- 显示 7.5 秒、空闲间隔 5 秒时，下一次定时器为 12.5 秒。
- 设置页目录选择器、显示时长、保存持久化及关联控件启停。

## 2026-08-27：多屏位置恢复与肥鱼版 DeepSeek 体验修复

### 多屏位置持久化

- 根因：桌宠此前只保存窗口中心相对当前屏幕可用区的比例 `rx/ry`，没有保存屏幕身份。应用开机自启时，新窗口最初通常归属主屏，恢复逻辑会把副屏比例直接套到主屏坐标上。
- 保存位置时新增 `screen_name`，与原有相对坐标一起持久化；启动恢复时优先在 `QGuiApplication.screens()` 中匹配该屏幕，再按该屏幕可用区还原位置。
- 旧配置没有 `screen_name`，或记录的副屏当前已断开时，继续回退到窗口当前屏幕或主屏，保持向后兼容并避免窗口落到不可见区域。
- 新增 `tests/test_window_position.py`，先复现副屏位置恢复成主屏坐标的失败，再覆盖副屏标识保存、启动恢复、屏幕查找和配置落盘。

涉及文件：`pet/window.py`、`pet/config.py`、`tests/test_window_position.py`。

### Harness 重复打开浏览器

- 根因：桌宠启动 `dsh web` 时未传 `--no-open`，Harness 自己打开一次浏览器；桌宠等待端口就绪后又调用 `webbrowser.open()`，最终出现两个浏览器界面。
- 所有启动命令解析分支共用的参数尾部新增 `--no-open`，浏览器统一由桌宠打开；服务已经运行时直接打开浏览器的原逻辑不变。
- 更新命令解析测试，明确要求 `web --host 127.0.0.1 --port 38080 --no-open`。

涉及文件：`pet/harness_launcher.py`、`tests/test_harness_launcher.py`。

### 消息卡片透明度配置

- 新增配置项 `modern_chat_card_opacity`，默认值为 `84`，合法范围为 `10–100`，读取旧配置时自动补默认值并规范化非法输入。
- 桌宠设置的外观页新增“消息卡片不透明度”；该控件只在“肥鱼版 DeepSeek”模式显示，切换到经典小手机模式时隐藏。
- 自定义背景下，助手、用户和错误消息卡片的 RGBA alpha 根据配置动态生成，默认视觉与原硬编码半透明效果保持一致。

涉及文件：`pet/config.py`、`pet/modern_settings_dialog.py`、`pet/chat/themes.py`、`pet/chat/widgets.py`。

### 当前角色头像与会话时间

- 肥鱼版 DeepSeek 左上角头像不再默认显示角色 ID 首字母，而是从当前 `PetWindow.icon_pixmap()` 取得裁剪后的当前角色帧图；角色切换或重新绑定桌宠窗口时同步刷新。无法取得图像时仍保留首字母兜底。
- 会话时间由 UTC ISO 时间直接格式化改为先调用 `astimezone()` 转换到系统本地时区，再生成“新会话 · HH:MM”，修复东八区等非 UTC 环境下的时间偏差。
