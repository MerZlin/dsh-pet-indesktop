## ⚠️ 升级说明

- 直接覆盖安装或换用新版便携版即可；配置目录按变体独立，不影响旧版数据，**无需迁移**。
- **本次有三处会改变老用户观感的行为变更**（都可在设置里改回去）：
  1. **自言自语「配图概率」默认 30%**（新配置键 `self_talk_image_chance`）。此前是「文本 + 图片拼成一张列表等权随机」，图片目录里几十张图时实际出图率可达 80%+，文本几乎轮不到；现在按你设的百分比掷骰。想恢复旧观感：把该值填成 `图数 ÷ (图数 + 文本数)`（例：24 张图 + 5 句文本 → 83%）；填 `0` = 只出文本。
  2. **点击台词朗读默认开**（`self_talk_speak_enabled`，设置 → 互动 → 点击与音效 → 点击反馈）。点击桌宠弹出的自言自语会用语音报时同一条音频通道念出来；不想听就关掉这一行。
  3. **「点击触发自言自语」的显示与朗读已解耦**：它现在**只看自己的开关**，不再要求「气泡自言自语」总开关也打开（此前关掉定时气泡会连点击台词一起消失）。
- 设置页布局：**设置 → 互动** 现在是两个页内标签（「点击与音效」/「自言自语」），侧栏 9 个域与各组名称不变；设置搜索命中非当前标签的行时会自动切过去。
- 新增 `music_player_paths`（设置 → 桌宠 → 音乐关联），留空即回到旧的自动搜索行为。
- **开着 VPN / 系统代理时歌词取不到词的问题已修**（#181）：歌词请求不再继承系统代理（三个源一律直连），顺带修好网易云等「不上报播放进度」播放器的右键「音乐 → 歌词对齐」（此前被误置灰）。逐功能影响面、30 秒排查法与推荐分流配置见 [`docs/NETWORK-PROXY-AND-VPN-2026-09-22.md`](NETWORK-PROXY-AND-VPN-2026-09-22.md)。
- 语音报时 / 节日提醒 / 台词自动预缓存仍**默认关闭**，按需开启。

## 🚨 重要声明 / 已知问题

- **系统通知仍未接入系统原生弹窗**（与 v4.2.0 相同）：AI 对话完成 / 生成失败 / 需要授权目前走应用自绘的右下角提示气泡，不能弹 Windows 操作中心 toast、macOS 通知中心或 Linux 桌面通知。
- **edge-tts 音色由微软随时上下架**：本版已加自动兜底（配置音色不在可用表里会自动改用默认音色并提示一次），但「可用音色表」来自在线接口、缓存 **6 小时**，最长 6 小时内可能仍按旧表判定。
- **台词自动预缓存需要本机语音服务**（CosyVoice，`http://127.0.0.1:9880` 的 `/health` 返回 `ok`）。没装就保持关闭——点击仍走在线合成，只是每次都要联网、首次出声有延迟。本机合成一句约 **20–60 秒**（服务带回读校验），所以只在后台做。
- **角色头部框数据已入库但尚未接线**：`assets/characters/shenshen/videos/manifest.json` 新增 `head_box`，取值函数 `pet/catalog.py character_head_box()` 已就位，但**边缘探头的锚点本版仍用整只轮廓**——「只露头」的观感变化不在本版。
- 安装包 / 安装器未签名（Windows SmartScreen、macOS Gatekeeper 需手动放行）；macOS 仅 Apple Silicon；Linux 仅 x86_64，建议 X11。
- **只有歌词取词绕过系统代理，其余联网功能仍跟随你的系统代理**（故意如此）：实测**更新检查**（`cdn.jsdelivr.net`）**只有走代理才能通**、edge-tts 端点直连也快，所以"全局绕过代理"会踩坏别的功能。开了 VPN 的用户若遇到语音/余额/识屏变慢或失败，先看 [`docs/NETWORK-PROXY-AND-VPN-2026-09-22.md`](NETWORK-PROXY-AND-VPN-2026-09-22.md) 里的逐功能清单与推荐设置。

### 🎵 音乐：歌词对齐与播放器定位

- **右键菜单「音乐 → 歌词对齐」**（#175）：回到开头 / 上一句 / 下一句 / 后退 5 秒 / 前进 5 秒。为什么需要它——实测**网易云音乐完全不上报播放进度**（SMTC `position` / `end_time` 恒为 `0.0`，播放中 / 暂停 / 切歌 / 快进四种状态采样一致），歌词只能按本地时钟估算，所以快进或从中途开始播必然错位；报进度的播放器会自动置灰并说明理由。同时把「开启功能时歌已经在播」从静默跳过改为**先亮歌名 + 提示一次可对齐**，并修「向后拖到第一句之前仍显示旧句」与多会话时跳到浏览器里那首歌（会话选择改为粘住当前播放器）。

### 🗣️ 台词朗读、本机语音预缓存与配图概率（#176）

- **点击台词朗读** `self_talk_speak_enabled`（默认**开**）：点击桌宠弹出的自言自语用语音报时的音色念出来，与报时共用音频通道、不叠音。
- **台词自动预缓存** `self_talk_voice_precache_enabled`（默认**关**）：保存设置后与每次启动 9 秒后，后台把「点击台词 + 点击动画绑定台词」合成为本机语音文件（`<配置目录>/self_talk_voice/<文本摘要>.wav`），命中即本地播放——**点击秒出、断网也能说**。幂等补齐（只补没有音频的句子）、单飞不叠线程、0 字节残文件当缺失重合成、服务不可用整轮跳过并记一条日志。

## 🐛 Bug 修复

### 音乐与歌词

- **开着 VPN / 系统代理时歌词整首不显示**（#181，用户反馈「合并前还能识别网易云歌词，合并后不行了」）：歌词取词原本走 `urllib.request.urlopen`，会**继承 Windows 系统代理**——开着全局模式 VPN（`127.0.0.1:12450`）时三个歌词源单次要 **41.3 / 22.1 / 20.4 秒**，全部超过 8 秒超时，于是每首**未缓存**曲目都在 9 秒死线处放弃（日志：`歌词取词完成: 陶喆 - 讨厌红楼梦 -> 0行, 耗时 9.00s`；命中磁盘缓存的歌照常显示）。修法：歌词请求改用**显式禁用代理的直连 opener**，并把请求失败原因从 `log.debug` 升到 `log.warning`（带主机、耗时、异常类型——此前 DEBUG 被 INFO 级配置吃掉，日志里只剩「0行」，根因被静默吞掉）。
  - 实测（同一首歌、真实网易云会话《蝴蝶》- 陶喆、代理保持开启）：**9.01 秒 / 0 行 → 0.88 秒 / 53 行**；未缓存曲目由 9 秒超时变为 **1 秒级**取词。
  - 判定要点：**取词代码与 v4.2.0 逐字节相同**（`git diff` 为空），坏它的是系统代理——这也解释了为什么"关掉代理就好了"。
- **网易云右键「音乐 → 歌词对齐」整组点不动**（#181）：网易云不上报 SMTC 播放进度（`position` / `end_time` 恒 0），歌词位置只能本地估算；但 `LyricTracker.load` 把**估算值**当成"播放器上报的真值"，于是 `align_available()` 判定「不需要手动对齐」把子菜单置灰——而同一个控制器刚弹过「快进后用菜单对齐校正」的提示。修后网易云可正常对齐；**QQ 音乐等真上报进度的播放器仍不许**手动对齐（护栏用例钉住）。

### 语音与提醒

- **edge 音色被下架后「配了音色却没声音」（#178）**。微软下架了 10 款 `zh-CN` 音色（晓辰 / 晓涵 / 晓梦 / 晓墨 / 晓秋 / 晓睿 / 晓双 / 晓萱 / 晓颜 / 晓悠），配置里指向它们时 `edge-tts` 抛 `NoAudioReceived: No audio was received. Please verify that your parameters are correct.`，用户只看到一句「语音合成失败（NoAudioReceived: …）」；更隐蔽的是缓存目录里留下的 **0 字节 mp3** 会被当成命中——播出一声静音且**永远不再重合成**。现在：
  - 配置音色不在可用表里 → **自动改用默认音色「晓晓」**，并提示一次：
    `音色「晓涵」已不在微软在线音色表里（多半被下架了），本次改用默认音色「晓晓」；可在 设置 → 语音 → 语音报时 → 音色 里换一个可用的。`（每进程只提示一次；`edge_tts` 不可导入时不替换，避免误导）
  - 每个候选音色最多**重试 2 次**（失败后间隔 **1.5 s**），全失败再退默认音色重试；错误串保留最后 4 条明细。
  - **0 字节缓存判为未命中**并清理半截产物 → 下次必然重新合成（服务端「成功但空文件」也算失败）。
  - 内置音色清单按微软在线表重建：**36 款（中文 14 + 英文 22）**；设置页里不在清单的值显示为「**不在清单里：<值>**」。
  - 实机复核：用已下架音色触发 → 自动改用默认音色并产出 22 752 字节音频；`list_voices()` 返回 322 款；连发失败的那批按间隔逐个重试全部成功。
- **语音报时/提醒链路的四则加固**（#159）：提醒队列死锁、客户端看门狗误杀新连接、菜单销毁后访问已删对象、POSIX 停止 dsh 残留子进程。
- **行为修复五则**（#160）：卡住检测定时剪枝、语音报时 busy 门改排队补播、预热分类口径统一、`quick_chat` 气泡形状、连接测试线程安全。
- **节日/报时默认关闭且默认不占右键菜单**（#157）。

### 桌面与交互

- **Windows 关机/注销必弹 `0xc0000142` 且阻塞关机**（#112，issue #111）：会话被拆除后仍 `CreateProcess` 新 ffmpeg；新增进程级「会话结束」闸门，四条 ffmpeg 派生路径全部拒绝。
- **点击桌宠夺走前台焦点 → 全局复制粘贴失效**（#121，issue #98）。
- **点击音效粘在错误态后永久静音**（#120，issue #116）。
- **气泡行尾字被裁切**、**打字时桌宠频闪**（#96 / #76 批）。
- **拖文件解读整文件读入卡死 GUI**（#152）→ 改有界读取。
- **移动-动画同步与朝向规则重写**（#157）：位移锁定步态整圈，消除「溜冰感」；朝向永远由目标决定。
- **灵动岛停靠细节**：左右停靠反复滑出/收回时细条持续上窜（#155）、移动续圈在圈边界一帧回退（#168）。
- **AI 会话窗「贴不到底」**（#153）：自己发的消息与 AI 回复都贴上边界、回复生成完还要手动上滑。
- **走路「卡」+ 抛掷动画偏慢 + 音效包扫描**（#182，贡献者 klxxya）：走路动画的位置交付只有 **28.6Hz** → 帧间补点后 **~160Hz @170Hz**；webm 冷路径原本在 **GUI 线程同步解码首帧**（碰撞压力下 >50ms 卡顿 **133 次 → 3 次**），改为冷路径首帧不阻塞 GUI、meta 探测后台化；抛掷飞行期动画按 `flight_anim_speed` 加速；音效包候选解析每帧 `iterdir` 扫盘 → 改进程级缓存（**0.43ms/次**命中）。实机做 300 秒走路 A/B、三开互撞 5 分钟复核。

### 碰撞与物理

- **岛碰撞鬼畜抽搐**（#173，Closes #146）：30Hz 检测改同步硬墙；鱼-鱼碰撞体改用**身体框**、抛掷中只挡不弹。
- **碰撞卡顿三连修**（#114）：落地预热离线程 / 飞行期首帧 pin / 岛内容层缓存。
- **多进程下的子肥鱼穿岛**（#182，贡献者 klxxya）：本进程没有岛就以为岛上没墙；子宠进程现在补挂远端硬墙，岛几何经碰撞 IPC 发布为静态成员（2s 心跳、变化合流 ≤10Hz），并加 `island_local_owned` 双重结算守卫。真机复核三开互撞 5 分钟 + 多进程岛墙场景。

### 平台与系统

- **Linux 屏幕边缘无法贴边**（#137，issue #103）：GNOME/mutter 会把移出工作区的窗口整体钳回，旧算式全部退化为 no-op；改为**虚拟窗口位置**语义，并引入角色包 `body_box` 稳定身体框通道。真机实测边缘间距 154 px → 个位数 px。
- **Windows CI 原生崩溃真凶**（#149）：`#140` 新增的播放器预热扫盘对盘根做三层浅扫、每播放器一条线程并发，与 Python GC 交叠后在原生层崩溃；改为 `_search` 全局串行化 + 测试进程内桩掉扫盘。
- **`#136` / `#131` 经 `#143` 撤出**：歌词显示的审计修复与节日动画/生日因上述崩溃被整批回退（真凶次日由 #149 定位）；歌词显示功能本体仍在，节日提醒（#127）不受影响。
- **`#164` 经 `#166` 回滚**：内置自言自语接回 `dialogue_mode` 风格路由的改动（`thinking` 键语义误用）已撤回。

### Agent 联动与 DSH

- **启动即按配置装配可选服务**（#100 / #102，issue #99）：重启后已开启的 Agent 联动与主动识屏开机不生效。
- **单进程多开下主动识屏永不触发**（#145）：`MultiWindowProxy._physics_mode` 返回 `False` 而非哨兵 `None`，使交互判定恒真、每次 8s tick 被静默拦截。
- **桥接插件归零外部依赖**（#104）：`link:` 安装不装被链接包自身依赖，打包副本解析失败会让 dsh web / headless / desktop 全 profile 起不来。
- **DSH 事件层系统性收尾**（#105）：cordis 审批链从未工作、问题气泡在 mux 断线时关不掉、5 个正常事件漏登记导致每次操作都伴随「请更新/重装 bridge」假提醒、无 pnpm 时卸载假成功。
- **余额多币种盲取首条**（#107）修「余额在 ¥0.00 与真实值之间跳动」；**Windows node/pnpm 解析不再写死**（#97）。
