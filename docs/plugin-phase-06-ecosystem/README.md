# Phase 6：插件生态

> **状态：条件启用（2026-09-25）**

Phase 6 不以“开放任意 Python 插件”为目标。是否实施取决于用户需求、维护成本、签名能力和安全边界。

## 推荐顺序

1. 发布 content DLC 的格式说明、校验工具和最小示例。
2. 根据实际作者反馈评估 content SDK、兼容矩阵和元数据规范。
3. 只有 `pet-worker/v1`、权限模型、配置摘要、签名发布和故障诊断稳定后，才评估 Worker SDK。
4. 第三方功能默认不进入 Core 进程；不承诺 Python 模块热卸载。

## 必须具备的能力

- capability 授权和最小权限；
- manifest、Core/API 兼容矩阵和弃用策略；
- 签名发布、公钥轮换和撤销；
- 社区 catalog 的审核、下架和诊断；
- 作者元数据、示例、测试和故障报告规范。

第三方生态是条件阶段，不影响 Core、官方资源 DLC、官方 in-process 插件和 Worker 的基础路线。
