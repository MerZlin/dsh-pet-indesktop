# Domain docs

This is a single-context repository.

Before exploring an area:

1. Read root `CONTEXT.md` when it exists.
2. Read relevant ADRs under `docs/adr/`.
3. Use glossary terminology consistently.
4. Explicitly flag proposals that contradict an ADR.

`CONTEXT.md` and ADRs are created lazily when a term or durable decision is
actually resolved.
